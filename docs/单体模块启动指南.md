# 短链接系统 — 单体模块启动指南

> 适用场景：本地开发调试。所有服务均单机运行，不依赖集群。

---

## 一、架构概览

| 模块 | 端口 | 说明 |
|------|------|------|
| **console-vue** | 5173 | Vue3 前端管理台（Vite） |
| **gateway** | 8000 | Spring Cloud Gateway 网关，统一入口 |
| **admin** | 8002 | 短链接后管服务（用户、分组、CRUD） |
| **project** | 8001 | 短链接核心服务（跳转、统计） |
| **aggregation** | 8003 | 聚合服务，把 admin + project 合并到一个进程 |

### 请求链路

```
浏览器 :5173  →  Vite 代理  →  Gateway :8000  →  Nacos 服务发现  →  Aggregation :8003
                                                                   ├─ Admin :8002
                                                                   └─ Project :8001
```

### 两种网关模式

| 模式 | Gateway 激活 profile | 原理 |
|------|---------------------|------|
| **分离模式** | `dev` | Gateway → `lb://short-link-admin` + `lb://short-link-project`，两个进程 |
| **聚合模式**（默认） | `aggregation` | Gateway → `lb://short-link-aggregation`，一个进程 |

> 日常开发用聚合模式就够了，少启动一个进程。

## 二、依赖中间件

| 中间件 | 地址 | 端口 | 用途 |
|--------|------|------|------|
| **MySQL 8** | 127.0.0.1 | 3306 | 数据存储（库名：`link`） |
| **Redis** | 127.0.0.1 | 6379 | 缓存、分布式锁、限流、Stream 消息 |
| **Nacos** | 127.0.0.1 | 8848 (gRPC 9848) | 服务注册与发现 |

## 三、启动前准备

### 1. 确认 MySQL 运行中，初始化数据库

```sql
CREATE DATABASE IF NOT EXISTS `link` DEFAULT CHARACTER SET utf8mb4;
```

确认连接信息（来自 `shardingsphere-config-dev.yaml`）：
- **库名**：`link`
- **用户**：`root`
- **密码**：通过 `SHORTLINK_DB_PASSWORD` 环境变量配置

> 如果密码不同，修改各模块 `src/main/resources/shardingsphere-config-dev.yaml` 中的 password。

### 2. 确认 Redis 运行中

```bash
redis-cli ping
# 返回 PONG 即正常
```

### 3. 启动 Nacos（Standalone 模式）

```powershell
# PowerShell
D:\nacos\nacos\bin\startup.cmd -m standalone
```

验证 Nacos 就绪：

```bash
curl http://127.0.0.1:8848/nacos/v1/console/health/readiness
# 返回 ok 即正常
```

Nacos 控制台：http://127.0.0.1:8848/nacos （默认账密：nacos/nacos）

## 四、编译打包

```bash
cd D:\短链接\shortlink

# 跳过测试，编译安装所有模块到本地仓库
./mvnw install -DskipTests
```

> 如果 `./mvnw` 报错找不到 wrapper，先执行 `mvn wrapper:wrapper` 重新生成。

---

## 五、启动后端

### 方式一：聚合模式（推荐，一个进程）

```bash
java -jar aggregation/target/shortlink-aggregation.jar
```

### 方式二：分离模式（两个进程）

```bash
# 终端1
java -jar admin/target/shortlink-admin.jar

# 终端2
java -jar project/target/shortlink-project.jar
```

### 启动网关

```bash
java -jar gateway/target/shortlink-gateway.jar
```

> 网关默认 `aggregation` profile。前端请求走网关，所以**必须先启网关再启前端**。

## 八、常见问题

### Q1: `mvnw` 启动报错找不到 `MavenWrapperMain`

**原因**：`.mvn/wrapper/` 目录丢失。

**解决**：
```bash
mvn wrapper:wrapper
```

### Q2: 编译报错 `非法字符: '�'`

**原因**：Java 源文件被改成了 UTF-8 with BOM 编码（常见于某些 IDE 自动格式化）。

**解决**：
```bash
find . -name "*.java" -type f -print0 | xargs -0 sed -i '1s/^\xEF\xBB\xBF//'
```

### Q3: Aggregation 启动后秒退

**原因**：Nacos 没启动。日志报 `Connection refused: 127.0.0.1:9848`。

**解决**：先启动 Nacos：
```powershell
D:\nacos\nacos\bin\startup.cmd -m standalone
```

### Q4: Maven install 报 `磁盘空间不足`

**原因**：Maven 本地仓库默认在 C 盘 `~/.m2/repository`，C 盘满了。

**解决**：把仓库搬到 D 盘：
```bash
# 1. 移动仓库
mv /c/Users/26916/.m2/repository /d/maven-repo

# 2. 配置 Maven settings.xml (~/.m2/settings.xml)
```

```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings>
  <localRepository>D:/maven-repo</localRepository>
  <mirrors>
    <mirror>
      <id>alimaven</id>
      <name>aliyun maven</name>
      <url>http://maven.aliyun.com/nexus/content/groups/public/</url>
      <mirrorOf>central</mirrorOf>
    </mirror>
  </mirrors>
</settings>
```

### Q5: 前端启动报错 / `npm` 找不到

**解决**：需要 Node.js。确认安装：
```bash
node -v   # 需要 16+
npm -v
```

如果 `node_modules` 丢失：
```bash
cd console-vue
npm install
```

### Q6: 端口被占用

```bash
# Windows 查看端口占用
netstat -ano | findstr :8003
# 强制杀掉
taskkill /PID <pid> /F
```

### Q7: 改了代码后如何生效

```bash
# 重新编译打包
./mvnw install -DskipTests

# 重启对应服务
java -jar aggregation/target/shortlink-aggregation.jar
```

### Q8: 前端改了不生效

Vite 有 HMR 热更新，改代码自动刷新。如果改了配置（`vite.config.js`）需要重新 `npm run dev`。
